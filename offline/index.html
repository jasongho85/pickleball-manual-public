📴 Offline Access

What works without an internet connection.

✅ Available Offline

When installed as a PWA, these features remain fully available even without an internet connection:

Drill descriptions and coaching cues
Execution checklists
Phase breakdowns and teaching focus
Poster images and stand-in visuals
Anatomy overlay images
Technique search and navigation

⚠️ Requires Connection

Video playback uses YouTube for delivery. These features require an active internet connection:

YouTube video playback (overview and phase videos)

📲 How to Install

To install Pickleball Kata as an app on your phone:

iPhone: Open in Safari → tap Share → "Add to Home Screen"
Android: Open in Chrome → tap the install banner or Menu → "Install app"
