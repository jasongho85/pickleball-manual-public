# Pickleball Manual - Deployment Output

This repository contains the **deployment output only** for the pickleball manual project.

## Purpose

This is a public repository that receives built static files from the private source repository (`pickleball-manual`). It serves as the hosting location for GitHub Pages publication.

## Publishing

The site is published via GitHub Pages from the `gh-pages` branch.

**Note:** Direct commits to this repository should not be made. All content is generated and deployed from the private source repository.
